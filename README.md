# Eltech (Moscow Polytech)

  <img src="Image/Logo.png" alt="Eltech App Icon" width="150" style="border-radius: 25px;"/>


**Eltech** is an unofficial mobile application for students and staff of Moscow Polytechnic University (Moscow Polytech). The application is developed natively for Android using Kotlin.

## 🚀 About The Project

This project was created to provide convenient and fast access to university services and information directly from a mobile phone.

## ✨ Key Features

* 📅 **Convenient Schedule:** View up-to-date class and practice schedules.
* 📄 **Digital Services:** Quickly order official documents and submit applications online, with status tracking.
* 🎓 **Track Your Grades:** Access session results and academic points.
* 🚀 **Project Activity:** Keep track of information on your academic projects.
* 🏃 **Physical Education:** Monitor attendance and points.
* 🗺️ **Campus Map:** Navigate university campuses and buildings.
* 💳 **Service Payments:** Access university payment services.

## 🛠️ Tech Stack

This project is built with 100% **Kotlin** and modern Android technologies.

* **UI:** [Jetpack Compose](https://developer.android.com/jetpack/compose), [Material 3](https://m3.material.io/)
* **Navigation:** [Navigation Compose](https://developer.android.com/jetpack/compose/navigation)
* **Architecture:** MVVM (Model-View-ViewModel)
* **Asynchronicity:** [Kotlin Coroutines](https://kotlinlang.org/docs/coroutines-overview.html)
* **Dependency Injection (DI):** [Koin](https://insert-koin.io/)
* **Networking:** [Ktor Client](https://ktor.io/docs/client-overview.html)
* **Data Parsing:** [Kotlinx Serialization](https://github.com/Kotlin/kotlinx.serialization) (for JSON), [Jsoup](https://jsoup.org/) (for HTML)
* **Database / Storage:** [Room](https://developer.android.com/jetpack/androidx/releases/room), [DataStore](https://developer.android.com/jetpack/androidx/releases/datastore), [Security Crypto](https://developer.android.com/jetpack/androidx/releases/security)
* **Image Loading:** [Coil](https://coil-kt.github.io/coil/)
* **Background Tasks:** [WorkManager](https://developer.android.com/jetpack/androidx/releases/work)
* **Widgets:** [Glance AppWidget](https://developer.android.com/jetpack/compose/glance)
* **SDKs:** [RuStore SDK](https://www.rustore.ru/help/sdk/tools) (AppUpdate, RemoteConfig)

## ⚙️ Getting Started (Installation)

1.  Clone the repository:
    ```sh
    git clone [https://github.com/rozetkaimg/Eltech.git](https://github.com/rozetkaimg/Eltech.git)
    ```
2.  Open the project in [Android Studio](https://developer.android.com/studio).
3.  Build the project (Build -> Make Project).
4.  Run on an emulator or a physical device.
